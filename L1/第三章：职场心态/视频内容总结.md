## 3.1 职场场景

- **文件：**`【3.1】职场场景.m3u8/index.m3u8`。
- **时长：**约14分49秒。
- **形式：**讲师讲授、课程框架回顾。

### 主题

这一节先说明为什么在组建或扩大团队之前，就应了解职场中的心态与行为，再把整章拆成个人、团队和组织三个层次。重点不是背几句正确的话，而是学会在真实沟通场景里观察人、理解团队和分析企业。

### 核心要点

1. **选人时就关注心态，胜过事后才发现不匹配。**讲师认为，团队发展到一定规模后才去纠正员工心态，成本高、改变也不容易；创业者可以提前用本章的视角观察候选人，而不是只在问题发生后补课。
2. **看知识之间的联系，不只看单独一张图。**回顾前几章，是为了理解价值观、心态、行为、沟通与运营框架之间的关系，避免只记细节而失去整体。
3. **运营要落实到价值和可量化结果。**讲师把为市场创造价值放在前面，把赚钱视为结果；谈运营时，要能说明实际产出，而不能只说明做了多少活动。他同时强调，框架的重要作用是把无序沟通变成有序沟通，提高协作效率。这些是讲师的运营观点，不是对经营结果的保证。
4. **职场可以看成一组不断切换的沟通场景。**从一对一，到几个人的小会，再到面向大量人的交流，一个工作日就在不同对象、角色和情境之间切换。因此，心态不能脱离场景来谈。
5. **三套框架对应不同的观察对象。**个人心态看一个人的修炼和行为；团队价值观看多人共事时的默契与调整；职场心态看一家组织的运行状态。本章后面的互动还会要求学员用职场框架观察一家具象的客户企业。

讲师还快速回顾了前两章的关联：从运营效率理解价值观与行为，关注休息与正向思维，认识到不同人看到的“现实”可能不同，多听对方的解释，减少噪音与过载，并把行为改变的方法真正用起来。他提到“20秒原则”等前课概念，但本段并未重新展开完整理论，不能只根据这次回顾补写其全部内容。

### 代表性例子

讲师用“一场会议接着下一场会议”的日常说明职场：每次面对的人数、对象和关系都可能不同。一个人在个人层面有自己的习惯，但进入团队后还要调整互动方式；观察客户企业时，又要上升到组织整体的层次。

### 可执行启发

- 分别选定三个观察对象：自己或一名具体同事、一个正在协作的团队、一家熟悉的客户企业，后续逐项对照，不混用评价层次。
- 招聘或沟通时，围绕真实行为和具体场景提问，不只听笼统的态度表态。
- 复习时画出价值观、行为、沟通与协作结果之间的联系，而不是只背八式的名称。

- 约00:00至01:21：为什么创业者应提前关注选人与心态。
- 约02:15至10:58：本章与前两章、运营框架的联系。
- 约11:27至14:49：职场沟通场景，以及个人、团队、组织三个层次。

## 3.2 个人心态

- **文件：**`【3.2】个人心态.m3u8/index.m3u8`。
- **时长：**约39分47秒。
- **形式：**框架讲解、打分练习、两位学员参与讨论。

### 主题

个人心态不是抽象的自我评价，而是在具体岗位和沟通场景中的行为倾向。讲师用八个维度帮助学员看自己或一名具体同事，并要求用观察到的行为解释分数。

### 个人心态八式

下表保留课件的两端词语。两端是课程用于观察运营效率的参照，不宜直接等同于对人的道德定性。

| 观察维度 | 课件的两端 | 理解重点 |
|---|---|---|
| 做事态度 | 敷衍 → 敬业 | 看对任务的真实投入和责任表现，而不只听表态。 |
| 处事心态 | 封闭 → 成长 | 遇到困难，是先说做不到，还是把它当成挑战并寻找办法。 |
| 处事行为 | 推脱 → 激情 | 接到任务后，是不断列借口，还是主动想办法推进。 |
| 面对岗位 | 越位 → 律己 | 结合角色和关系判断如何介入，以及能否有效沟通。 |
| 价值观 | 薪酬 → 增值 | 不只关心待遇，也关心岗位内容、企业价值和自身成长。 |
| 面对资源 | 私人 → 公司 | 如何看待客户与平台资源，以及个人努力和公司支持的关系。 |
| 价值取向 | 喜欢 → 需要 | 是否愿意持续学习，承担虽不讨喜但为成长和工作结果所必需的事。 |
| 行为表现 | 利己 → 利他 | 看行为对他人、团队和共同结果的影响。 |

### 评分的两种用法

讲师先给出的是**习惯养成的阶段评分**：

| 分数 | 阶段 |
|---|---|
| 0 | 没有意识 |
| 1 | 有意识 |
| 2 | 有意愿去改变 |
| 3 | 将改变行为进入计划 |
| 4 | 定期检查改变进度 |
| 5 | 成为习惯 |

这六个阶段也是培养人的过程：先建立意识，再形成意愿，把行为列入计划，持续检查，最终成为习惯。知道一个道理，并不等于已经做到。

为便于当堂互动，讲师又临时简化为**在低效与高效两端之间做直观评分**，例如敷衍的一端为0分、敬业的一端为5分。它与上面的习惯阶段评分不是同一种具体判分方式，不能混为一谈；两者都要回答“凭什么给这个分”，用实际行为作根据。

### 讲解中的重要区分

- **成长心态不以“全部看清楚”作为开始行动的唯一前提。**讲师指出，碰到难题就断言做不到、没时间学，或任何事情都要先完全看清才敢做，都会限制发展；观察重点是面对挑战的反应。
- **关注合理薪酬不是问题。**讲师承认新员工为了生活而关注薪酬可以理解；他反对的是一直只谈待遇，却没有兴趣了解岗位职责、工作内容和能创造什么价值。
- **“越位”不能脱离场景判断。**学员谈到给供应商提出管理意见，对方有时认为她管得太多。讲师补充，作为对外合作的老板，介入不一定是坏事；供应商做不好会影响自己的结果，关键是怎样有效沟通、引导和影响对方。
- **“需要”包括持续成长，也包括不讨喜但不可省略的工作。**讲师反对学到“够用”就停下来；学员则用销售交付说明，有些繁琐工作不能立刻增加销售额，却是实现交付和客户价值所必需的。
- **学习不是拿框架挑别人的错。**一位学员反省，过去容易觉得自己总是对的，供应商交付不及时就生气；后来更愿意先理解对方的资源和能力限制，帮助双方改进。讲师把利他与影响力联系起来，学员也以同时考虑客户、供应商的合作价值来说明自己的理解。

### 代表性例子与学员复盘

**客户资源与“野蛮生长”。**一位学员说，过去在贸易公司，获客、沟通、交付都由销售自己完成，容易放大个人贡献，忽略平台；现在经营公司，他希望在这些环节给销售支持，形成公司与个人的配合。另一位学员虽然也经历过放任成长，却没有把客户当私人资源，现在还给团队提供线索和陪练。讲师提醒，后一种心态不能被当成普遍的招聘前提，应理解现实、建设支持条件。

**从喜好走向成长与交付。**学员用推进新产品项目、学习供应商的情况、完成繁琐交付等行为解释自评分数。也有人讲到，曾接受明显降薪，换取在更大平台学习的机会。这是学员个人的经历与选择，不是要求所有人放弃合理薪酬。

**32分不是这一节的目的。**一位学员最后自评32分，对应课件的“职场达人”。讲师随即强调，重要的不是称号，而是刚才逐项寻找了什么行为、有没有因此更了解自己和他人。

### 总分标签与工具的边界

八项每项最高5分，总分40分。课件给出以下复习标签：

| 总分 | 课件标签 |
|---|---|
| 0-8 | 新秀 |
| 8-16 | 加倍努力 |
| 17-24 | 明日之星 |
| 25-36 | 职场达人 |
| 37-40 | 未来CEO |

**原文说明：**前两档在8分处重叠，按课件原文保留，未擅自修改。标签只是课堂工具，不是正式职业资格或未来表现的预测。

讲师还明确说明，八项不是唯一、封闭的标准，只是便于呈现的一个工具箱；数量可以调整。用来培养员工时，可以在某个阶段或一个季度里先选择一项需要提升的行为，不要同时要求一个人八项全改。

### 可执行启发

- 先固定一个观察对象，再逐项写下分数与一条真实行为证据，不在同一张评分表里随意换人。
- 从当前最影响工作的一项入手，把“态度不好”改写成可以观察的行为目标，列入计划并定期检查。
- 招聘、带人和自我复盘都可以借用框架，但不要用总分掩盖单项问题，也不要期待找到一个天生八项全好的员工。
- 对合作方有不同意见时，先弄清自己的角色、对方的困难与共同结果，再考虑怎么表达才能产生影响。

- 约00:00至06:30：观察对象、评分规则与行为举证。
- 约06:32至21:58：八式解释，以及薪酬、资源与平台支持的讨论。
- 约21:59至35:48：学员自评，供应商协作与销售交付案例。
- 约35:48至39:47：分数不是目的，八式是工具箱，培养行为应聚焦。

## 3.3 团队价值观

- **文件：**`【3.3】团队价值观.m3u8/index.m3u8`。
- **时长：**约23分16秒。
- **形式：**团队框架讲解、学员观察案例讨论。

### 主题

个人有能力，不代表多人共事就有战斗力。讲师把团队价值观放在协作场景中讨论：观察一个团队如何沟通、协调和处理分歧，才能看出它是在增效还是内耗。尚未建立自己团队的人，也可以借客户或供应商的团队来练习观察。

### 核心要点

1. **管理者的价值要体现在团队效率上。**讲师认为，管理者进入团队后应改善协作，而不是只增加管理动作和内部消耗。
2. **培训个人技能有用，但不足以形成团队战斗力。**单个人能力更强，不一定更容易协调。团队还需要共同的做事方式、默契和沟通，让成员互相补位；讲师用“1+1=3”比喻这种协同效果。
3. **进入一个团队，要先识别它已有的做事方式与价值观。**不要只按自己的习惯判断别人；先观察人们如何讨论事情、如何配合以及什么行为被认可。
4. **团队价值圈是动态的，不是给人永久贴身份标签。**随着组织发展、要求提高，成员在不同圈层之间可能发生变化。讲师据个人经验强调，不能只指望原有成员永远构成全部团队，保持人才联系和引入新血应成为常态，而不只在缺人时临时招聘。

### 动态团队价值圈

讲师用以下示意解释团队中认同、差异与底线的关系：

- **核心价值圈约10%：**对团队价值观高度认同的一部分成员。
- **约80%的圈层：**不可能全部、完全契合，需要沟通、协调和一定妥协。
- **底线之外的退出示意约10%：**妥协不能没有底线；有人离开，也为新成员进入留下空间。
- **新血持续进入：**带来新的能力和做事方式，推动团队继续提高要求；原来的核心成员也可能进入其他圈层。

**信息边界：**讲师提到这一比例与调研、个人职业经验有关，但本段没有给出具体研究出处。这里将10%／80%／10%作为讲师的示意框架记录，不把它视为所有团队必须符合的统计定律，也不把它当作硬性的人员淘汰配额。

### 团队价值观八式

| 观察维度 | 课件的低效一端 | 课件的高效一端 |
|---|---|---|
| 同事之间 | 互相质疑 | 互相欣赏 |
| 讨论事情 | 对人 | 对事 |
| 互动关系 | 互茬 | 互补 |
| 做事态度 | 少做少错 | 持续提升 |
| 面对问题 | 打小报告 | 直接讨论 |
| 组织行为 | 山头主义 | CEO心态 |
| 团队目标 | 关注政治 | 关注业绩 |
| 做事作风 | 言而无信 | 言出必行 |

### 代表性例子与讲师点评

**互相质疑的供应商团队。**一位学员在多次拜访某供应商后，观察到领导觉得下属不干事，下属觉得领导不管事；老板习惯委婉表达，下属更直接，冲突后老板带着情绪不再支持。老板又担心员工做出高业绩后离开，团队因此出现少做少错、山头和内部消耗。这是学员基于接触作出的观察，用来练习分析，并非本次对该企业进行独立调查得出的结论。

**先维护自己能够接触的价值传递链。**另一位学员承认，合作方内部也有不如意之处；但他重点维护与自己业务相关的销售、方案、技术、电气、工程、调试和生产环节，让自己对接的链条尽量在高效的一侧协作。这说明，尚不能改变整个组织时，可以先改善自己能接触的沟通与交付关系。

**CEO的低效行为可能与意识、习惯和环境有关。**学员描述，有的老板处理销售冲突时，按亲疏和个人喜好，而不是共同规则。讲师追问：他是刻意这样做，还是不知道高效行为是什么？双方也讨论了“关注权威”与“关注运营效率”的区别。讲师建议，用分享最近学到的框架、询问对方看法的方式，了解对方是否已经建立意识，再尝试产生影响。

讲师还用自己初任CEO时缺乏系统指导的个人经历提醒学员：不要仅凭职位，就假设对方已经懂得高效组织行为。对合作方保持理解和同情，也有助于找到有效的沟通入口。

### 可执行启发

- 选择一个真实团队，逐项记录成员如何讨论事情、是否互补、是否兑现承诺，不只给出“团队内耗很大”的笼统结论。
- 将分歧拉回事情、协作和共同结果；欣赏与互补并不等于没有分歧，而是减少对人的消耗。
- 无法改变整个客户或供应商组织时，先维护自己能接触的价值传递链。
- 试着向负责人分享框架、讨论具体情境，先弄清他是否认识到问题与另一种做法，而不是直接贴上“故意低效”的标签。
- 人才联系和团队底线可以常态化，但不要机械地按示意比例给成员分档或淘汰。

## 3.4 职场心态

- **文件：**`【3.4】职场心态.m3u8/index.m3u8`。
- **时长：**约23分32秒。
- **形式：**企业案例讨论、业务数据追问、运营工具与沟通机制的联系。

### 主题

这一节把视角从个人和局部团队，扩展到一家企业的整体运行环境。不能只认识某一名客户联系人，就以为了解了整家公司；还要观察部门协作、计划、执行、文化、领导力、目标和沟通机制。

### 职场心态八式

| 观察维度 | 课件的低效一端 | 课件的高效一端 |
|---|---|---|
| 部门关系 | 内斗 | 协作 |
| 做事方法 | 救火 | 计划 |
| 执行力 | 光说不练 | 专注执行 |
| 企业文化 | 偏重资历 | 尊重表现 |
| 领导力 | 下有对策 | 上有政策 |
| 工作环境 | 政治 | 做事 |
| 面对目标 | 迷茫 | 清晰 |
| 沟通环境 | 堵塞 | 畅通 |

表中词语按课件保留；本段并未逐项给出独立操作手册，重点是把这些维度带入真实企业的运行场景中观察。

### 正向供应商案例

一位学员换用一家评价较好的供应商举例。她观察到，技术人员不仅配合业务需求，还会从专业角度提出设计问题，像解决方案伙伴一样融入协作；团队事先讨论计划、资源与时间安排，执行也比较迅速。她还提到负责人重视品质、为人亲和，给合作方较强的信任感。

但她对企业文化的一些细节、公司总人数等并不了解。因此，讲师虽然认可这些表现值得研究，却没有把“我很喜欢这家供应商”直接当成对企业整体的充分判断。

### 关键转折：追问“4个销售、约4.5亿元”的口径

学员提到销售人员约4人，年销售额约4.5亿元。讲师没有直接接受这一组合，而是连续追问：

- 销售人员、老板分别如何参与获客与跟单？是否能把总营收直接归到4名销售？
- 产品在客户的整套系统里是什么位置，单价、数量和客户结构能否相互解释？
- 营收是太阳能相关产品线的数据，还是还包含工业产品和总公司的其他业务？
- 学员对接业务的目标、部门业绩与总公司营收，是不是混用了不同口径？

讨论中逐渐发现，老板也参与客户开发，企业不只有太阳能相关业务，学员知道的局部信息不足以解释整组数字。她提出继续向合作方了解数据、查看能够分享的资料，但本段并没有完成核实。

**因此，“4个销售、约4.5亿元”在这里是需要进一步解释和求证的课堂口述数据，不是已经确认的企业事实，也不是已经证明的个人销售效率。**这一段示范的是如何通过业务结构和数据口径追问判断，而不是用几个漂亮数字给企业贴上“完美”的标签。

### 不期待完美伙伴，先提高协作与理解

另一位学员说，不期待遇到完全完美的客户或供应商；他会了解价值传递链上每一个对接人的情况，维护合作关系，让订单沟通与执行更有效。讲师也提醒，有些正向印象来自了解还不够深入；企业可以有明显优势，也仍有值得继续追问的地方。

### 六分仪与Commit Call怎样连接本章

**六分仪。**本段提到用这一课程工具梳理业务目标、客户采购或项目成交、执行差距及差距来源。学员用其设备业务中“成交／未成交”的例子说明，要回看客户需求、组织关系、竞争价格和客户名单的选择，而不是只看结果数字。本段没有重新介绍六分仪的完整结构与计算方法，这里不补造公式。

**Commit Call。**英文拼写已按视频约21:10、21:14的字幕核对。讲师把它作为一种**有序沟通机制**讨论：在实际沟通过程中，可以看到部门是否协作、是否有计划、是否执行、企业文化和领导力如何、目标是否清晰，以及沟通是否畅通。

这把本章与运营工具连起来：框架和机制让沟通有序，而人的心态、团队互动和组织环境，决定这些沟通是否真正有效。讲师据此强调缺乏这种机制的团队会偏向低效一侧；本段未展开完整的会议操作流程，因此不补写固定频率、议程或模板。

### 可执行启发

- 分清“我认识某个联系人”与“我理解这家公司”，从跨部门协作、目标、计划和实际沟通过程继续观察。
- 遇到看似优秀或异常的数据，先确认主体、范围、时间和业务口径，再尝试用业务流程解释，不急着下结论。
- 用运营分析工具找目标与实际的差距，再判断是客户选择、需求理解、组织关系、价格还是内部协作的问题。
- 参与或观察有序沟通机制时，留意八个维度的真实表现，不只看有没有开会、有没有一张表。
- 承认合作方可能不完美，先在自己能影响的环节改善沟通；这不等于对所有问题无限妥协，仍要有明确边界。

### 回看片段

- 约00:00至03:47：从个人、团队转到企业整体，并观察正向供应商的协作、计划与执行。

- 约13:37至16:36：不期待完美伙伴，继续核实企业信息与业务数据。

## 共同主线与复习建议

### 一句话串起整章

**用可观察的行为理解个人，用协作方式理解团队，用运行机制和口径清楚的数据理解企业；再把需要改变的行为放进实际计划与沟通中。**

### 四段之间的关系

- **3.1搭观察框架：**职场是一组沟通场景，个人、团队和企业要分层看。
- **3.2从个人行为入手：**评分只是促成观察与习惯改变的工具，要用行为举证，并聚焦一项改进。
- **3.3关注协作与环境：**个人能力不等于团队战斗力；共同做事方式、价值底线、互补和兑现承诺都很重要。
- **3.4把判断放回企业运行：**不能用好感或单个数字代替理解；通过业务分析和有序沟通机制，观察是否产生有效结果。

### 本章反复强调的提醒

1. **观察先于贴标签。**说明具体发生了什么，再讨论心态、价值观或组织问题；也要确认对方是缺少意识、习惯使然，还是在刻意选择。
2. **框架是工具箱，不是不可调整的戒律。**同一个条目，放在员工、老板、供应商和客户身上，角色与场景可能不同，不能机械套用。
3. **改变要经过过程。**从没有意识到形成习惯，中间还有意愿、计划和定期检查；一次要求八项全改，很难有效。
4. **个人心态与组织支持相互影响。**不要只期待招到“天生正确”的员工，也要建设资源支持、共同标准和有效沟通环境。
5. **利他落实在共同价值与结果中。**关注客户、合作方和团队需要，并不等于否定合理薪酬、放弃边界，或用工作时长代替有效产出。

### 可直接使用的复盘记录

下面是根据课程整理的记录方式，不是讲师另给出的新评分制度。

| 观察层次 | 固定一个对象 | 记一条真实证据 | 下一步 |
|---|---|---|---|
| 个人 | 自己或一名具体同事 | 某项任务中的回应、行动与结果 | 选一项最关键的行为，进入计划并定期检查 |
| 团队 | 自己的团队，或客户／供应商团队 | 一次分歧如何讨论、怎样配合、是否兑现承诺 | 先改善自己能够接触的协作链条 |
| 企业 | 一家具体客户或供应商公司 | 跨部门沟通表现，以及口径明确的业务信息 | 找出未了解或解释不通的部分，继续观察与求证 |
