# 第六章：演讲能力｜视频内容总结

**本章要解决的不是「如何把一段稿子念好」，而是「如何让合适的人听懂你能帮他什么，并愿意往下谈」。** 五节课围绕同一个场景展开：老李要在峰会上做一次分论坛分享，借机会让潜在客户了解团队的价值。

共 5 节，合计 **2 小时 8 分 2 秒**。整理依据为每节视频的完整音轨，并用课件关键帧和画面字幕交叉核对。时长按播放列表四舍五入到秒，回看时间从各节视频开头计。

## 6.1 为什么要演讲？

**文件：** `【6.1】为什么要演讲？.m3u8/index.m3u8`　**时长：** 37:38

- **先让人愿意听，再追求讲得有条理。** 开头回顾了运营创造价值、利他心态、健康状态、职场沟通和建立互信。与本章最直接相关的是「先有效、再有序」：如果听众对讲者有防备，内容再有逻辑也难以听进去；互信则要靠持续、可靠的沟通维护，不能指望一开口就成交。
- **演讲是一对多的沟通，互动不会自动发生。** 课件用从一对一交谈、小组会到公开演讲的图说明：人数越多，自然互动越少。讲师以自己的做法举例：在几十人到百人左右、场地允许时，边讲边走近不同区域的听众，让他们感到自己正在被交流，而不是只听台上的人独白。
- **企业负责人要能亲自把价值说清楚。** 老李从小镇木匠开店做起，逐步做到企业客户，在朋友老陈帮助下转型做框架落地服务。老陈邀他在峰会分论坛分享经验；他怕没有公开演讲经验，想找人代讲。老陈反问：团队里有谁比你更能讲清自己做过的事？老李意识到，过去是老陈开公开课替他引来客户，现在该练习自己把团队经验说给市场听。课件把这看作企业代言人的工作，也是 L2C 的前端：先让别人对企业的核心价值产生兴趣。老陈同意继续帮他，把这次峰会当成迈出第一步的机会。

**课堂例子：** 一位学员在智能制造协会年会上做了首次五分钟公开分享。起初她和老李一样担心讲不好；准备时反复缩小范围，想清楚自身核心能力、为哪些客户创造什么价值。讲完后，她发现这次练习不仅让同行知道自己做什么，也反过来帮自己梳理了业务方向和客户选择。

**可以怎么做：** 先列一个自己有第一手经验的题目，用「我们遇到什么问题、如何处理、哪些变化值得讲」搭一段三分钟分享。先对小范围听众试讲，问对方听完记住了什么、还想了解什么，再准备正式上台。

**回看：** `09:14` 前后讲有效与有序沟通；`15:18` 前后看互动示意图；`18:30` 起看老李案例；`31:48` 起听五分钟演讲的学员复盘。

## 6.2 演讲的目的

**文件：** `【6.2】演讲的目的.m3u8/index.m3u8`　**时长：** 22:10

- **区分「为什么要练」与「这一场要达到什么目的」。** 练习演讲是为了能自己讲清团队价值；具体到这场论坛，先定会后希望发生什么，再决定内容。老李现有客户多是通过公开课认识的。课件把来参加公开课的人称为「线索」；公开课用价值主张激起他们的兴趣，并判断谁有足够兴趣继续沟通。峰会分享也承担同样的任务：争取后续交流的机会，而不是把所有听众在现场变成客户。
- **价值主张不是口号，而是听众愿意继续谈的理由。** 讲到自己的经验时，要能让目标对象发现「这个问题我也有，这个人可能能帮我」。谁到场和谁愿意往下谈，是两个不同的信号，不宜只用现场人数或掌声判断效果。讲师也强调，签合同只是持续沟通中的一站，不能让任一次沟通断了后续。

**课堂反馈：** 一位学员在行业年会上做完短分享，晚宴上有同业主动来认识、加微信并提到潜在合作，这是后续跟进的信号，还不意味着已谈成合作。另一位学员一次拜访没能见到原约的采购负责人，改见未见过的采购人员；没急着推在谈项目，而是先聊当地情况，分享公司的进展和解决过的问题，也问清对方的采购流程，结果对方愿意留下联系方式、给出介绍。讲师用这个例子说明：一对一也可以传递价值和建立互信，只是更便于追问、交换信息，覆盖人数则比公开演讲少。

**讲师的补充：** 认识客户不必只盯着最高负责人。实际经手的人通常更了解流程和问题，管理者和执行者提供的信息也不同。讲师建议尽量在项目启动前建立联系；如果项目已明确归某人负责，就要尊重对方的沟通安排，别让合理的拜访被理解为绕过负责人。

**可以怎么做：** 写稿前先填一句话：「我希望〔哪类人〕听完后愿意〔做一个什么动作〕。」例如，分享结束后愿意预约一次需求沟通、带一个真实问题来讨论。用这个目标筛掉好听但无助于下一步的内容。

**回看：** `01:35`–`04:30` 前后看公开课如何引出「线索」；`06:08` 起听一对一拜访的案例。

## 6.3 客户的画像

**文件：** `【6.3】客户的画像.m3u8/index.m3u8`　**时长：** 33:11

- **先确定讲给谁听，再设计价值主张。** 等参会者从峰会议程里自行选中分论坛比较被动。老陈建议从报名名单中筛出希望邀请的对象，主动发信说明论坛内容，再由销售跟进。接受了邀请的人至少对这个主题有一点好奇，比到了现场临时选会场的人更可能愿意听。这是讲师所说的先打开「情绪层」。
- **不确定谁是目标时，先问谁不是。** 老李说，自己不太确定谁是客户，反而比较有把握说出哪些人不合适。也不要拿一个特别成功的客户当作整个市场的画像。老招是老李的第一个客户，也是重要的支持者，但他身为较大企业的 CEO，肯放下身段接受小团队的帮助，这一点并不常见。其他同规模企业并非没有问题，却未必愿意以同样的方式合作；规模太小的企业又可能承担不起框架落地的成本，也不一定看得出效果。老李于是把初步目标收敛为：**规模在 1 亿到 5 亿之间、做 ToB 项目型业务的企业**。这个业务形态跟他过去做过的项目相近，更有经验可以复用；数字只是案例里的筛选条件。

**课堂例子：** 一位制造业学员以前有单就接，表面上有利润的订单常被生产中的隐性成本吃掉。她后来聚焦航空航天装备，按自己企业的能力列名单：暂时够不到的头部先建立联系，有现实合作机会的重点跟进。她带着目标逛展会，拿到引荐后在展后及时联系。讲师指出，长期面对同类问题，工艺和交付经验才更容易积累，也更有机会解决客户没想到的问题，而不是每接一个单都重新摸索。

另一位学员把「眼下为了维持经营要接的订单」与「值得长期投入的目标客户」分开，却仍拿不准规模远超自己的大企业是不是合适的目标。讲师提醒，画像要靠实际接触、交付和反馈逐步跑出来；先在一个看得见发展空间的细分市场做深，形成可复用的能力，再考虑拓展，不必一开始就跨很多行业。

**可以怎么做：** 从真实服务过的几类客户中，分别找出「我们反复解决过的问题」「客户愿意投入的条件」和「少数成功个案的特殊条件」。先用规模、行业或业务形态等可识别的条件圈定名单，再用邀请回应、访谈或跟进结果修正画像。

**回看：** `00:35`–`04:30` 前后讨论主动邀约；`05:50`–`12:40` 前后从老招的例子推导目标画像；`12:53` 起听制造业学员如何从接单转向选客户。

## 6.4 价值主张

**文件：** `【6.4】价值主张.m3u8/index.m3u8`　**时长：** 18:00

- **听众不一定认识自己的痛点。** 老李发现，有些企业只知道「不赚钱」，却不清楚问题有多严重、不改变会有什么后果，也不知道还能不能改。老李准备先把痛点说具体、尽量量化，再说明改善思路和实际案例。这样听众可以先认出自身处境，再判断解决方式是否适用。
- **价值主张要回答五个问题。** 课件依次列出「要解决的问题、解决问题的思路、为什么是你、成功案例、进一步了解」。用听众的处境开头；先讲到足以让人判断是否靠谱，不必在初次分享中拆解完整方案；再说明自己做过哪些相似的事情，用贴近听众的案例证明做法不是空想；最后告诉有兴趣的人怎么继续了解。
- **以对方愿不愿意继续谈作为这场论坛的判断标准。** 课件用 LG（lead generation，线索获取）概括这项动作。讲师提醒，L2C 不同阶段要讲的价值不同；在线索获取阶段点到为止，给双方留下进一步了解的机会。案例中，老李计划邀约 100 家目标企业，老陈认为实际到场以 50–70 人左右为宜，再看邀约反应；这些是本场活动的考虑，不是所有论坛的配额。

**课堂例子：** 一位学员最初只是向矿山采购介绍自己的产品，对方兴趣不大。小规模合作开始后，她改为就履约情况征求意见，每次拜访前列出想了解的问题，也倾听对方遇到的困难。她说，持续的交流让对方逐渐愿意见面讨论更多话题。另一位学员复盘短讲时发现，简要介绍公司，把篇幅留给亲历的行业问题和实际做法，比着重宣传公司更容易让人听进去。

**可以怎么做：** 用「具体问题 → 改善思路 → 为什么由我们来做 → 一个同类案例 → 一个会后入口」写一页提纲。案例尽量说清起点、做法、结果，有可核实的数据才写，不用夸张的承诺替代证据。

**回看：** `02:00`–`04:50` 前后看老李如何从痛点走到线索获取；`05:07`–`10:56` 前后看价值主张五项；`11:20` 起听矿山采购案例。

## 6.5 高效演讲的考虑

**文件：** `【6.5】高效演讲的考虑.m3u8/index.m3u8`　**时长：** 17:03

课件列出八项。它们不只适用于上台，也可以用来回看日常沟通：

| 课件要点 | 讲师如何解释 |
| --- | --- |
| 营造轻松气氛 | 紧张、板着脸的场子不利于交流，先让自己和听众放松。 |
| 铺垫互动环境 | 讲师以在香港大学讲课举例：提前到，先和前排几位打招呼、了解他们。上台后可以看向已经聊过的人，从眼神和肢体语言获得反馈；互动不一定要听众正式发言。 |
| 说人话 | 每句话都要考虑对方能否听懂；不确定时，换成通俗、具体的说法，不堆术语。 |
| 经验分享 | 讲自己的实际经历，而不是把经验包装成所有人都得同意的理论。这样既有内容可讲，也能缓解怕说错的压力。 |
| 避免万事通 | 不知道就承认，记下问题，会后查清再答复。讲师甚至会邀请学员提出自己答不出来的问题，把它当作学习机会。 |
| 讲故事 | 把观点放进真实场景，讲清人物遇到的事情和做法，比只念理论更容易让人听进去。 |
| 数据说话 | 「市场不错」「质量好」不够具体。用相关数据、比较基准或变化来解释自己的判断。 |
| 三明治方法 | **先预告要讲哪几件事 → 展开并用故事支撑 → 回顾刚讲了什么。** 讲师自己的做法是，即使有一小时，也尽量不超过三条希望听众记住的信息。 |

**课堂反馈：** 一位学员用「我是打铁的」开场，以自己的从业和经营经历做五六分钟的短分享；她反复推倒重来，最后用简单的话讲清楚。另一位学员原以为只需和采购一对一谈，进场才发现技术、车间等多人在场，紧张之下改成照读 PPT，几乎没有交流。讲师也有过以为见四个人、却被带进七十多人的教室的经历。他提醒，不必把应对不完美看成白做；复盘听众、现场条件和互动准备，才会把经历变成下一次能用的经验。

**可以怎么做：** 彩排时问听众「刚才最记得哪一点？」如果答不出来，就删减信息、把专业词换掉，补一个真实故事或一组对比。提前安排一个容易回应的互动点，结尾重提关键信息及后续动作。

**回看：** `00:59`–`03:23` 前后看如何铺垫互动；`05:04`–`07:44` 前后看如何应对答不出的提问；`09:05`–`10:28` 前后看三明治方法。

## 贯穿五节课的准备顺序

**为什么由我讲 → 听完希望对方做什么 → 该讲给谁听 → 哪个价值能打动他们 → 怎样让人听懂、记住并愿意回应。** 老李案例里的终点是有意愿继续沟通的线索。换成内部汇报，可以把「下一步」换成做决策、分派责任或确认一个问题，不必照搬销售目标。

下次准备发言，可以先填这五行，再打开 PPT：

1. **听众：** 谁在场？他们正在解决什么问题？
2. **目标：** 我希望他们会后做的一个具体动作是什么？
3. **主张：** 我能帮助他们改变什么？为什么听我讲？
4. **证据：** 哪一个亲历故事和哪一组可信数据最有说服力？
5. **讲法：** 需要听众记住哪一到三条？开头如何让人愿意听，现场如何互动，最后如何引向下一步？
